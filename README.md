# Series Metric Searcher, a Lucene index visualizer for series information

Series Metric Analyzer is an app powered by Apache Lucene that allows you to visualize information indexes from your favourite series.

The program will perform a tokenization, hunspell and synonymy morphological analysis of the search query you introduce. 
It will search in the given index those information. 

You can use this to get interesting information about a series like when certain themes take place within the series, what places in the environment appear more given those themes, what characters tend to improve or worsen in the episodes, what themes certain characters tend to talk about, etc.

You can create indexes with this app in [SeriesMetricAnalyzer](https://github.com/RedRiotTank/SeriesMetricAnalyzer).
